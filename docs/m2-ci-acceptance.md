# CI continuation for isolated M2 acceptance

This acceptance targets only `acceptance/m2-owner-continuity`.
The persistent Task owner diagnoses bound-PR CI failures and repairs them in the same work session.
Authorized in-scope follow-up comments remain attached to that work and receive an owner judgment.
CI evidence stays tied to the checked revision; older results remain historical after a repair.
The host commits repairs and runs fresh validation and required independent review at fixed versions.
Merge requires current head/base and remote check evidence under the existing delivery gates.
The host owns finalization and platform replies; owner continuity preserves those responsibilities.
