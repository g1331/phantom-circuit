# Reuse pinned engineering skills with host-enforced operations

Use Matt Pocock's engineering skill formats and practices at a fixed revision, with role-specific adaptations in project prompts. The PM acts as the delegated technical decision-maker, while the host enforces claims, limits and external mutations; prompt text alone cannot enforce concurrency or grant authorization. A worktree isolates code changes but is not a security boundary against malicious programs running as the same OS user.
